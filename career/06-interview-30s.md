# 30-Second Interview Explanation

"I run an independent research project called VibeGuardBench. The question is:
when an AI app builder generates a full-stack web application and automated tools
find real defects in it, can the builder repair those defects without breaking
functionality that already worked? I built a benchmark with three frozen app
specifications and a 39-check deterministic test suite — functional, security,
authorization, accessibility, build, and persistence checks — plus automated
repair feedback and full-suite re-runs after every repair so regressions get
counted. The protocol is preregistered and the harness is validated end-to-end;
the main experiment with commercial builders is in progress. Everything is open
source, including the audit trail of what has and hasn't been run."
